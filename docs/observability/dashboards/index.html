    Dashboards

    Sourcegull's Grafana dashboards, one per service. They are generated from crates/monitoring into deploy/docker/grafana/dashboards/ (in the Compose bundle, to import into your Grafana) and the Helm chart's dashboard ConfigMaps (metrics.grafanaDashboards.enabled=true); README.md shows how to set them up. Panels with alerts link to alerts.md.

    #Sourcegull: web

    The web role serves the UI, the GraphQL and HTTP APIs, streaming search, code host webhooks and the executor API.

    Grafana uid: sourcegull-web.

    #web: HTTP requests

    web_http_request_rate

    Requests per second by route

    Requests to the public listener by matched route pattern (fallback is the UI and raw files). Health checks and scrapes are left out.

    promql
    sum by (route) (rate(sourcegull_http_requests_total{role=~"web|all",route!~"/metrics|/healthz|/readyz"}[5m]))

    Owner: platform

    web_http_5xx_ratio

    Share of requests answered with 5xx

    • Alert (warning): web: share of requests answered with 5xx above 2% for 5m
    • Alert (critical): web: share of requests answered with 5xx above 10% for 10m
    promql
    (sum(rate(sourcegull_http_requests_total{role=~"web|all",route!~"/metrics|/healthz|/readyz",status=~"5.."}[5m])) or 0 * sum(rate(sourcegull_http_requests_total{role=~"web|all",route!~"/metrics|/healthz|/readyz"}[5m])))
/ sum(rate(sourcegull_http_requests_total{role=~"web|all",route!~"/metrics|/healthz|/readyz"}[5m]))

    Owner: platform

    web_http_p90_latency

    90th percentile request duration by route

    • Alert (warning): web: 90th percentile request duration by route above 5s for 15m
    promql
    histogram_quantile(0.9, sum by (le, route) (rate(sourcegull_http_request_duration_seconds_bucket{role=~"web|all",route!~"/metrics|/healthz|/readyz|/.api/search/stream|/.api/compute/stream|/.api/blame/.*|/.api/scip/upload|/.api/files/.*|/.executors/.*"}[5m])))

    Owner: platform

    web_site_config_version

    Site configuration version loaded by each instance

    The site config version each process runs with. With the config in the database, all instances converge on the same version within seconds of a change; a lasting difference means an instance cannot reload it (its logs say why). With SOURCEGULL_SITE_CONFIG_FILE, versions count reloads per process and may differ.

    promql
    max by (role, instance) (sourcegull_site_config_version)

    Owner: platform

    #Sourcegull: repo

    Repo nodes clone and fetch repositories from the code hosts, build the text search index and serve git data and searches to the other roles over gRPC.

    Grafana uid: sourcegull-repo.

    #repo: Disk

    repo_disk_free_ratio

    Free disk space on the data volume

    Measured by the repo node janitor (2 minutes after start, then hourly). The node pauses clones when free space is below both SOURCEGULL_REPO_PAUSE_CLONES_FREE_PERCENT (default 10%) of the volume and SOURCEGULL_REPO_PAUSE_CLONES_FREE_GIB (default 20 GiB); Site admin > Repo nodes shows the threshold.

    • Alert (warning): repo: free disk space on the data volume below 15% for 10m
    • Alert (critical): repo: free disk space on the data volume below 5% for 5m
    promql
    min by (instance) (sourcegull_repo_disk_free_bytes{role=~"repo|all"} / sourcegull_repo_disk_total_bytes{role=~"repo|all"})

    Owner: source

    repo_disk_free_bytes

    Free bytes on the data volume

    Free space for clones, the search index and caches, measured hourly. A repo node needs about 1.5 times the size of its repositories.

    promql
    min by (instance) (sourcegull_repo_disk_free_bytes{role=~"repo|all"})

    Owner: source

    #repo: Rebalancing

    repo_repo_moves

    Repository moves between repo nodes by state

    After repo nodes are added or removed, the repositories whose node changes are copied to their new node (queued, copying), switched over (flipped, the old copy is kept for a few minutes) and then removed from the old node. Nothing moves until every repo node runs with the same node list.

    promql
    max by (state) (sourcegull_repo_moves)

    Owner: source

    max by (queue, state) (sourcegull_queue_jobs{queue=~"codeintel_index_jobs|batch_spec_workspace_execution_jobs",state=~"failed|errored"})

    Owner: platform

    #executor: Executor API

    executor_api_requests

    Executor API requests per second by route

    Heartbeats, dequeues, log updates, git and file downloads from executors.

    promql
    sum by (route) (rate(sourcegull_http_requests_total{role=~"web|all",route=~"/.executors/.*"}[5m]))

    Owner: platform

    executor_api_5xx_ratio

    Share of executor API requests answered with 5xx

    • Alert (warning): executor: share of executor API requests answered with 5xx above 5% for 15m
    promql
    (sum(rate(sourcegull_http_requests_total{role=~"web|all",route=~"/.executors/.*",status=~"5.."}[15m])) or 0 * sum(rate(sourcegull_http_requests_total{role=~"web|all",route=~"/.executors/.*"}[15m])))
/ sum(rate(sourcegull_http_requests_total{role=~"web|all",route=~"/.executors/.*"}[15m]))

    Owner: platform

    #Sourcegull: blob

    The blob role stores SCIP uploads, bulk change workspace files and search job results on its volume and serves them to the other roles. With an S3-compatible store (blobstore.mode=s3) there is no blob role and this dashboard stays empty.

    Grafana uid: sourcegull-blob.

    #blob: Requests

    blob_request_rate

    Blob requests per second by method and status

    PUT writes, GET/HEAD reads, DELETE removals. 404 on reads is normal for missing keys.

    promql
    sum by (method, status) (rate(sourcegull_blob_requests_total{role=~"blob|all"}[5m]))

    Owner: platform

    blob_error_ratio

    Share of blob requests answered with 5xx

    • Alert (warning): blob: share of blob requests answered with 5xx above 1% for 10m
    • Alert (critical): blob: share of blob requests answered with 5xx above 10% for 10m
    promql
    (sum(rate(sourcegull_blob_requests_total{role=~"blob|all",status=~"5.."}[10m])) or 0 * sum(rate(sourcegull_blob_requests_total{role=~"blob|all"}[10m])))
/ sum(rate(sourcegull_blob_requests_total{role=~"blob|all"}[10m]))

    Owner: platform

    blob_p90_latency

    90th percentile blob request duration by method

    Until the response starts: reads stream their body afterwards, writes include receiving the upload.

    promql
    histogram_quantile(0.9, sum by (le, method) (rate(sourcegull_blob_request_duration_seconds_bucket{role=~"blob|all"}[5m])))

    Owner: platform

    #blob: Instances

    blob_instance_up

    Instances answering Prometheus scrapes

    1 while Prometheus can scrape the instance's internal listener (:6060), 0 when it cannot.

    • Alert (critical): blob: instances answering Prometheus scrapes below 1 for 5m
    promql
    up{role=~"blob|all"}

    Owner: platform

    #Sourcegull: postgres

    Sourcegull's database, measured by the workers (pg_stat_activity, database size) and by every process (its connection pool). For server-level metrics (replication, I/O, vacuum), run a Postgres exporter next to it.

    Grafana uid: sourcegull-postgres.

    #postgres: Database

    postgres_postgres_up

    Workers reaching Postgres

    1 when the last metrics collection by a worker (every 30 s) reached Postgres, else 0.

    • Alert (critical): postgres: workers reaching Postgres below 1 for 5m
    promql
    max(sourcegull_postgres_up)

    Owner: platform

    postgres_connections

    Connections to Sourcegull's database by state

    From pg_stat_activity. Many idle in transaction connections point to transactions left open by a client.

    promql
    max by (state) (sourcegull_postgres_connections)

    Owner: platform

    postgres_connection_saturation

    Share of max_connections in use by Sourcegull's database

    • Alert (warning): postgres: share of max_connections in use by Sourcegull's database above 80% for 5m
    • Alert (critical): postgres: share of max_connections in use by Sourcegull's database above 95% for 5m
    promql
    sum(max by (state) (sourcegull_postgres_connections))
/ max(sourcegull_postgres_max_connections)

    Owner: platform

    postgres_oldest_transaction

    Age of the oldest open transaction

    • Alert (warning): postgres: age of the oldest open transaction above 30m for 5m
    promql
    max(sourcegull_postgres_oldest_transaction_seconds)

    Owner: platform

    postgres_database_size

    Size of Sourcegull's database

    Grows with repositories, code graph data and job history. Watch the free space of the Postgres volume.

    promql
    max(sourcegull_postgres_database_size_bytes)

    Owner: platform

    #postgres: Connection pools

    postgres_pool_in_use

    Pool connections in use by process

    Connections each process has checked out of its pool. Workers next to other roles get a separate worker pool.

    promql
    max by (role, instance, pool) (sourcegull_db_pool_connections{state="in_use"})

    Owner: platform

    postgres_pool_saturation

    Share of the connection pool in use by process

    • Alert (warning): postgres: share of the connection pool in use by process above 90% for 15m
    promql
    max by (role, instance, pool) (sourcegull_db_pool_connections{state="in_use"} / ignoring(state) sourcegull_db_pool_connections{state="max"})

    Owner: platform
