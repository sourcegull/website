Features

Everything a code search platform needs. All of it free.

No enterprise edition, no licence key. The features other products sell separately are in the same Apache-2.0 repository.

Search that keeps up

Literal, regexp, keyword (BM25) and structural search over a trigram index of its own. After a push, only changed paths are re-indexed, so new commits are searchable within seconds. Any branch, tag or commit that isn't indexed is searched straight from git. Results stream as they're found.

  • regexp
  • BM25
  • structural
  • any revision
  • search jobs → CSV

Precise code navigation

Go to definition, find references and implementations from SCIP indexes, across repositories and package versions. Search-based results fill in where there's no index.

Built for AI agents

A built-in MCP server lets coding agents search, read files, jump to definitions and read history, with the caller's permissions, in output sized for a model's context.

SSO, SCIM, RBAC, audit

OAuth, OpenID Connect or an auth proxy; SCIM provisioning; roles; an audit log. Repository permissions are synced from the code host and enforced on every read.

Bulk changes

One YAML spec changes many repositories, then opens and tracks the GitLab merge requests.

Trends and watches

Chart how code changes over time, such as how many files still use a deprecated API, and get notified when new commits match a search.

Every code host at once

gitlab.com, self-managed GitLab, GitHub and Gitea side by side; one search covers them all, each with its own permissions.

Code intelligence

From a search hit to every caller in two clicks

Hover any symbol for its signature and docs. Definitions and references open in a panel below the code, across every repository the index knows about.

  • SCIP indexes uploaded from CI or built by auto-indexing
  • Cross-repository and cross-version references
  • Blame, history, compare and code ownership too

AI agents

Your agents read the answer, not the repository

Connected over MCP, an agent reads only the lines that answer its question: 5× to 70× fewer tokens than cloning and grepping. Any agent that speaks MCP can connect with just the server URL and a sign-in or access token, and every tool runs with that user's repository permissions.

Install

Running in about a minute

one host
curl -fsSL https://github.com/sourcegull/sourcegull/releases/latest/download/sourcegull-compose.tar.gz | tar -xz
cd sourcegull-compose
echo "POSTGRES_PASSWORD=$(openssl rand -hex 24)" > .env
docker compose up -d

Open http://localhost:7080. The first user to sign up becomes the site admin; add a code host under Site admin → Code host connections.

kubernetes
helm install sourcegull oci://ghcr.io/sourcegull/charts/sourcegull \
  --set externalURL=https://sourcegull.example.com

Then open your externalURL; the first user to sign up becomes the site admin.
